# Changelog

## 0.1.0 - 2026-05-29

- Package Linux-only `codex-mcp-clean` CLI.
- Add `list`, `snapshot`, `report`, and dry-run-by-default `cleanup` commands.
- Scope cleanup by Codex app-server PID and snapshot/cutoff timestamp.
- Detect Serena, Telegram, YouTrack/mcp-remote, Context7, Playwright, and Slack MCP launchers.
- Add JSON output for diagnostic reports.
